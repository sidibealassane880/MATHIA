1. ALGÈBRE

Chapitre 1 : Les ensembles de nombres

Les différents ensembles de nombres

Les nombres sont regroupés dans plusieurs ensembles.

  • ℕ : les nombres entiers naturels : 0, 1, 2, 3...
  • ℤ : les nombres entiers relatifs : ..., -2, -1, 0, 1...
  • 𝔻 : les nombres décimaux : 2,5 ; -3,25...
  • ℚ : les nombres rationnels, qui peuvent s'écrire sous forme de fraction.
  • ℝ : les nombres réels.
ℕ ⊂ ℤ ⊂ 𝔻 ⊂ ℚ ⊂ ℝ
Exemple : 5 appartient à ℕ, ℤ, 𝔻, ℚ et ℝ. Le nombre -3 appartient à ℤ, 𝔻, ℚ et ℝ.
Exercice 1 : Le nombre -7 appartient à quel ensemble ?
Chapitre 2 : Les opérations sur les nombres réels

Addition, soustraction, multiplication et division

Les nombres réels permettent d'effectuer les quatre opérations fondamentales.

a + b : somme
a - b : différence
a × b : produit
a ÷ b : quotient (si b ≠ 0)

Les règles de priorité

  1. Les parenthèses.
  2. Les puissances.
  3. Les multiplications et divisions.
  4. Les additions et soustractions.
Exemple :
A = 5 + 3 × 2
A = 5 + 6
A = 11
Exercice 1 : Calculer 4 + 3 × 5.
Exercice 2 : Calculer (8 + 4) ÷ 3.
Chapitre 3 : Développement et factorisation

Le développement

Développer consiste à transformer un produit en somme.

a(b + c) = ab + ac
3(x + 4) = 3x + 12

La factorisation

Factoriser consiste à transformer une somme en produit.

ab + ac = a(b + c)
5x + 15 = 5(x + 3)

Identités remarquables

(a + b)² = a² + 2ab + b²
(a - b)² = a² - 2ab + b²
(a + b)(a - b) = a² - b²
Exercice : Développer 2(x + 5).
Exercice : Factoriser 4x + 12.
Chapitre 4 : Les équations du premier degré

Définition

Une équation est une égalité contenant une inconnue, souvent notée x.

ax + b = 0, avec a ≠ 0

Méthode de résolution

Résoudre : 2x + 6 = 14
2x = 14 - 6
2x = 8
x = 8/2
x = 4
Exercice : Résoudre 3x + 6 = 15.

2. GÉOMÉTRIE

Chapitre 1 : Droites et angles

Les différents types d'angles

  • Angle aigu : inférieur à 90°.
  • Angle droit : égal à 90°.
  • Angle obtus : compris entre 90° et 180°.
  • Angle plat : égal à 180°.
Deux angles complémentaires ont une somme de 90°.
Deux angles supplémentaires ont une somme de 180°.
Si deux angles sont supplémentaires et que le premier mesure 65°, le deuxième mesure 180° - 65° = 115°.
Exercice : Un angle de 40° est complété par quel angle ?
Chapitre 2 : Les triangles

Les types de triangles

  • Triangle équilatéral : trois côtés égaux.
  • Triangle isocèle : deux côtés égaux.
  • Triangle rectangle : un angle droit.
  • Triangle quelconque : aucune propriété particulière obligatoire.
La somme des angles d'un triangle est toujours égale à 180°.
Si deux angles mesurent 50° et 60°, alors le troisième mesure : 180° - 50° - 60° = 70°.
Exercice : Un triangle a deux angles de 60° et 60°. Quel est le troisième ?
Chapitre 3 : Les quadrilatères

Définition

Un quadrilatère est un polygone qui possède quatre côtés.

  • Le carré : quatre côtés égaux et quatre angles droits.
  • Le rectangle : côtés opposés égaux et quatre angles droits.
  • Le losange : quatre côtés égaux.
  • Le parallélogramme : côtés opposés parallèles.
La somme des angles d'un quadrilatère est 360°.
Exercice : Combien mesure chaque angle d'un carré ?
Chapitre 4 : Le théorème de Thalès

Énoncé

Lorsque deux droites sécantes sont coupées par deux droites parallèles, les longueurs correspondantes sont proportionnelles.

Si (BC) est parallèle à (DE), alors :
AB/AD = AC/AE = BC/DE
Si AB = 3, AD = 6 et AC = 4, alors :
3/6 = 4/AE
AE = (6 × 4)/3 = 8.
Exercice : Si AB = 2, AD = 6 et AC = 3, calculer AE.

3. FONCTIONS

Chapitre 1 : Généralités sur les fonctions

Définition

Une fonction est une relation qui associe à chaque nombre x de son domaine de définition un unique nombre appelé image de x.

f : x → f(x)

Image et antécédent

Si f(2) = 5, alors :

  • 5 est l'image de 2.
  • 2 est un antécédent de 5.

Exemple de tableau de valeurs

x-2-1012
f(x)=2x+1-3-1135

Fonction linéaire et affine

Fonction linéaire : f(x) = ax
Fonction affine : f(x) = ax + b
f(x) = 3x + 2
f(2) = 3 × 2 + 2 = 8.
Exercice 1 : Si f(x) = 2x + 3, calculer f(4).
Exercice 2 : Si f(x) = 5x, calculer f(3).
Chapitre 2 : Sens de variation d'une fonction

Fonction croissante

Une fonction est croissante lorsque ses images augmentent quand x augmente.

Fonction décroissante

Une fonction est décroissante lorsque ses images diminuent quand x augmente.

Fonction constante

Une fonction est constante lorsque ses images restent les mêmes.

f croissante : x₁ < x₂ implique f(x₁) ≤ f(x₂).
f décroissante : x₁ < x₂ implique f(x₁) ≥ f(x₂).

Exemple : f(x) = 2x + 1

Comme son coefficient directeur est positif (2), elle est strictement croissante sur ℝ.

Exemple : f(x) = -3x + 4

Son coefficient directeur est négatif (-3), elle est strictement décroissante sur ℝ.

La fonction carré f(x) = x² est décroissante sur ]-∞ ; 0] et croissante sur [0 ; +∞[. Elle possède un minimum égal à 0 en x = 0.

Chapitre 3 : Les fonctions usuelles

Introduction

Les fonctions usuelles sont des fonctions mathématiques fréquemment utilisées. Nous allons étudier quatre fonctions : la fonction carré, la fonction cube, la fonction inverse et la fonction racine carrée.

1. La fonction carré

f(x) = x²

La fonction carré associe à chaque nombre réel son carré.

  • Domaine de définition : ℝ.
  • Elle est décroissante sur ]-∞ ; 0].
  • Elle est croissante sur [0 ; +∞[.
  • Son minimum est 0, atteint pour x = 0.
x-2-1012
x²41014
Pour x = 3 : f(3) = 3² = 9.
Pour x = -4 : f(-4) = (-4)² = 16.

2. La fonction cube

f(x) = x³
  • Domaine de définition : ℝ.
  • Elle est strictement croissante sur ℝ.
  • Elle prend des valeurs négatives, nulles ou positives.
x-2-1012
x³-8-1018
f(2) = 2³ = 8.
f(-3) = (-3)³ = -27.

3. La fonction inverse

f(x) = 1/x
  • Domaine de définition : ℝ privé de 0.
  • Elle n'est pas définie pour x = 0.
  • Elle est décroissante sur ]-∞ ; 0[.
  • Elle est également décroissante sur ]0 ; +∞[.
x-2-112
1/x-1/2-111/2
f(2) = 1/2.
f(-4) = -1/4.
Attention : on ne peut jamais diviser par zéro.

4. La fonction racine carrée

f(x) = √x
  • Domaine de définition : [0 ; +∞[.
  • Elle n'est pas définie dans ℝ pour les nombres négatifs.
  • Elle est strictement croissante sur son domaine.
x014916
√x01234
√25 = 5 car 5² = 25.
√49 = 7 car 7² = 49.

4. STATISTIQUES

Chapitre 1 : Vocabulaire statistique

Définitions

  • Population : ensemble des individus étudiés.
  • Individu : élément de la population.
  • Caractère : propriété étudiée.
  • Effectif : nombre d'individus.
  • Fréquence : rapport entre un effectif et l'effectif total.
Fréquence = Effectif / Effectif total
Dans une classe de 40 élèves, 10 sont absents.
Fréquence des absents = 10/40 = 0,25 = 25 %.
Exercice : Dans une classe de 30 élèves, 15 sont des filles. Quelle est leur fréquence ?
Chapitre 2 : Moyenne, médiane et étendue

La moyenne

Moyenne = Somme des valeurs / Nombre de valeurs
Série : 10, 12, 14, 16.
Moyenne = (10 + 12 + 14 + 16)/4 = 13.

La médiane

La médiane partage une série ordonnée en deux groupes de même effectif.

Série : 2, 4, 6, 8, 10.
La médiane est 6.

L'étendue

Étendue = Valeur maximale - Valeur minimale
Pour 3, 5, 8, 10 : étendue = 10 - 3 = 7.
Exercice : Calculer la moyenne de 4, 6 et 8.
Chapitre 3 : Les représentations graphiques

Les différents graphiques

  • Diagramme en bâtons : comparer des effectifs.
  • Diagramme circulaire : représenter des proportions.
  • Histogramme : représenter des données regroupées en intervalles.
  • Courbe : montrer l'évolution d'une grandeur.
Exemple : une classe compte 20 élèves.
10 aiment le football, 6 aiment le basketball et 4 aiment le volleyball.
Pour un diagramme circulaire :
Angle = Fréquence × 360°
