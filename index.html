CHAPITRE 1 : LES ENSEMBLES DE NOMBRES

I. Objectifs pédagogiques

À la fin de ce chapitre, l'élève doit être capable de :

  • Reconnaître les différents ensembles de nombres.
  • Classer un nombre dans un ensemble.
  • Utiliser les symboles mathématiques.
  • Comparer des nombres réels.
  • Déterminer si un nombre est rationnel ou irrationnel.
  • Représenter et interpréter des intervalles.

II. Les nombres naturels (ℕ)

Les nombres naturels sont les nombres utilisés pour compter. Ils commencent par zéro et continuent indéfiniment.

ℕ = {0 ; 1 ; 2 ; 3 ; 4 ; 5 ; ...}

Exemples : 0, 1, 8, 25, 100 et 1000 appartiennent à ℕ.

En revanche, -3 et 2,5 n'appartiennent pas à ℕ.

Exemple 1 :

Parmi les nombres 5 ; -2 ; 0 ; 8,5 ; 12, identifier les nombres naturels.

Correction :

5 ∈ ℕ ; 0 ∈ ℕ ; 12 ∈ ℕ.

-2 ∉ ℕ et 8,5 ∉ ℕ.

III. Les nombres entiers relatifs (ℤ)

Les entiers relatifs comprennent les nombres positifs, les nombres négatifs et zéro.

ℤ = {... ; -3 ; -2 ; -1 ; 0 ; 1 ; 2 ; 3 ; ...}

Exemples : -15, -4, 0, 7 et 125.

Exemple 2 :

Classer : -8 ; 0 ; 14 ; -2,5 ; 100.

Correction :

-8 ∈ ℤ ; 0 ∈ ℤ ; 14 ∈ ℤ ; 100 ∈ ℤ.

-2,5 ∉ ℤ car il n'est pas entier.

IV. Les nombres décimaux (D)

Un nombre décimal possède une écriture décimale finie.

Exemples : 2,5 ; 3,75 ; -4,125 ; 8 = 8,0.

Les nombres 1/2 et 3/4 sont aussi décimaux car ils peuvent s'écrire 0,5 et 0,75.

Attention : 1/3 = 0,333... n'est pas un nombre décimal.

Exemple 3 :

Dire si 0,125 est décimal.

Oui, car son écriture décimale est finie.

On peut également écrire 0,125 = 125/1000 = 1/8.

V. Les nombres rationnels (ℚ)

Un nombre rationnel peut s'écrire sous forme d'une fraction de deux entiers dont le dénominateur est non nul.

ℚ = {a/b ; a ∈ ℤ et b ∈ ℤ*}

Exemples : 1/2 ; 3/4 ; -7/5 ; 5/1.

Tout nombre décimal est rationnel.

Exemple 4 :

Montrer que 0,75 est rationnel.

0,75 = 75/100.

En simplifiant par 25 :

0,75 = 3/4.

Donc 0,75 ∈ ℚ.

VI. Les nombres irrationnels

Un nombre irrationnel ne peut pas s'écrire sous la forme d'une fraction de deux entiers.

Son écriture décimale est infinie et non périodique.

Exemples : √2 ; √3 ; π.
Exemple 5 :

Classer √4 ; √5 ; √9 et √7.

√4 = 2 : naturel.

√5 : irrationnel.

√9 = 3 : naturel.

√7 : irrationnel.

VII. Les nombres réels (ℝ)

L'ensemble des réels comprend les nombres rationnels et les nombres irrationnels.

ℝ = ℚ ∪ ensemble des irrationnels

Exemples : -5 ; 2,5 ; 1/3 ; √2 et π appartiennent à ℝ.

VIII. Relations entre les ensembles

ℕ ⊂ ℤ ⊂ D ⊂ ℚ ⊂ ℝ

Tout nombre naturel est un entier relatif. Tout entier relatif est un nombre décimal. Tout décimal est rationnel. Tout rationnel est réel.

Exemple 6 :

Quel est le plus petit ensemble contenant 12 ?

12 ∈ ℕ.

Le plus petit ensemble contenant 12 est donc ℕ.

IX. Les symboles mathématiques

∈ : appartient à
∉ : n'appartient pas à
⊂ : est inclus dans
⊄ : n'est pas inclus dans
∪ : réunion
∩ : intersection

Exemples : 5 ∈ ℕ ; -2 ∈ ℤ ; 1/3 ∉ D ; ℕ ⊂ ℤ.

X. Comparaison des nombres réels

On utilise les symboles suivants :

< : inférieur à
> : supérieur à
≤ : inférieur ou égal à
≥ : supérieur ou égal à

Tout nombre positif est supérieur à tout nombre négatif.

Entre deux nombres négatifs, celui qui est le plus proche de zéro est le plus grand.

Exemple 7 :

Ranger dans l'ordre croissant : -5 ; 3 ; -2 ; 0 ; 7.

Correction :

-5 < -2 < 0 < 3 < 7.

XI. Les intervalles

Un intervalle est un ensemble de nombres réels compris entre deux bornes.

[a ; b] : intervalle fermé
]a ; b[ : intervalle ouvert
[a ; b[ : fermé à gauche
]a ; b] : fermé à droite
Exemple 8 :

Écrire 2 ≤ x < 7 sous forme d'intervalle.

2 est inclus, 7 est exclu.

x ∈ [2 ; 7[.

XII. Résumé à retenir

ℕ : naturels
ℤ : entiers relatifs
D : décimaux
ℚ : rationnels
ℝ : réels
ℕ ⊂ ℤ ⊂ D ⊂ ℚ ⊂ ℝ

📐 GÉOMÉTRIE

1. Définition du triangle

Un triangle est un polygone possédant trois côtés, trois sommets et trois angles.

2. Somme des angles

A + B + C = 180°
Exemple : 60° + 70° + 50° = 180°.

3. Le théorème de Pythagore

Dans un triangle rectangle, le carré de l'hypoténuse est égal à la somme des carrés des deux autres côtés.

BC² = AB² + AC²
AB = 3 cm et AC = 4 cm.
BC² = 3² + 4² = 9 + 16 = 25.
BC = √25 = 5 cm.

4. Théorème de Thalès

Lorsque deux droites sécantes sont coupées par deux droites parallèles, les longueurs correspondantes sont proportionnelles.

AM/AB = AN/AC = MN/BC

5. Exercice

Un triangle rectangle possède deux côtés de 6 cm et 8 cm. Quelle est son hypoténuse ?

📈 FONCTIONS MATHÉMATIQUES

1. Définition

Une fonction associe à chaque valeur x de son domaine une unique valeur f(x).

2. Image d'un nombre

L'image d'un nombre est le résultat obtenu en calculant la fonction pour cette valeur.

Soit f(x) = 2x + 3.
f(4) = 2 × 4 + 3 = 11.

3. Antécédent

L'antécédent de y est un nombre x tel que f(x) = y.

f(x) = 2x + 3.
Cherchons l'antécédent de 11.
2x + 3 = 11.
2x = 8.
x = 4.

4. Fonction affine

f(x) = ax + b

a est le coefficient directeur et b l'ordonnée à l'origine.

5. Fonction linéaire

f(x) = ax

Sa représentation graphique est une droite passant par l'origine.

6. Exercice

Soit f(x) = 3x + 2. Calculer f(2).

📊 STATISTIQUES

1. Définition

La statistique est une branche des mathématiques qui permet de collecter, organiser, analyser et interpréter des données.

2. Effectif

L'effectif est le nombre de fois qu'une valeur apparaît dans une série statistique.

3. Fréquence

Fréquence = Effectif / Effectif total

Le pourcentage est égal à la fréquence multipliée par 100.

4. Moyenne

Moyenne = Somme des valeurs / Nombre de valeurs
Notes : 10 ; 12 ; 14 ; 16.
Moyenne = (10 + 12 + 14 + 16)/4 = 13.

5. Médiane

La médiane est la valeur qui partage une série ordonnée en deux groupes de même effectif, selon la convention usuelle de calcul.

Série : 4 ; 6 ; 8 ; 10 ; 12.
La médiane est 8.

6. Étendue

Étendue = Valeur maximale - Valeur minimale
Série : 5 ; 8 ; 12 ; 15.
Étendue = 15 - 5 = 10.

7. Exercice

Calculer la moyenne de 8, 10 et 12.
