Algèbre

Chapitre 1 : Les ensembles de nombres

1. Objectifs

  • Reconnaître les différents ensembles de nombres.
  • Classer un nombre dans un ensemble.
  • Utiliser les symboles d'appartenance et d'inclusion.
  • Comparer des nombres réels.

2. Les nombres naturels

Les nombres naturels sont utilisés pour compter.

ℕ = {0 ; 1 ; 2 ; 3 ; 4 ; 5 ; ...}

3. Les nombres entiers relatifs

Ils comprennent les nombres positifs, négatifs et zéro.

ℤ = {... ; -3 ; -2 ; -1 ; 0 ; 1 ; 2 ; 3 ; ...}

4. Les nombres décimaux

Un nombre décimal possède une écriture décimale finie.

Exemples : 2,5 ; 0,75 ; -3,125 ; 12.

5. Les nombres rationnels

Un nombre rationnel peut s'écrire sous la forme :

a/b avec a ∈ ℤ et b ∈ ℤ, b ≠ 0

6. Les nombres irrationnels

Un nombre irrationnel ne peut pas s'écrire comme quotient de deux entiers.

Exemples : √2, √3 et π.

7. Les nombres réels

ℕ ⊂ ℤ ⊂ 𝔻 ⊂ ℚ ⊂ ℝ

Les nombres réels regroupent les nombres rationnels et irrationnels.

8. Exemples corrigés

7 appartient à ℕ, ℤ, 𝔻, ℚ et ℝ.
-4 appartient à ℤ, 𝔻, ℚ et ℝ, mais pas à ℕ.
√5 est irrationnel et appartient à ℝ.

9. À retenir

  • Tout naturel est un entier relatif.
  • Tout entier relatif est décimal.
  • Tout décimal est rationnel.
  • Tout rationnel est réel.

Chapitre 2 : Opérations sur les nombres réels

1. Addition

Deux nombres de même signe : on additionne leurs valeurs absolues et on conserve le signe.

(-4) + (-6) = -10
(+5) + (+3) = +8

Deux nombres de signes contraires : on soustrait les valeurs absolues et on conserve le signe du plus grand.

(+9) + (-4) = +5
(-12) + (+7) = -5

2. Soustraction

a - b = a + (-b)
8 - 3 = 5
-5 - 4 = -9
-7 - (-2) = -5

3. Multiplication

(+) × (+) = (+)
(-) × (-) = (+)
(+) × (-) = (-)
(-) × (+) = (-)
(-4) × (-2) = 8
(-6) × 3 = -18

4. Division

La division suit les mêmes règles de signes que la multiplication. Le diviseur doit être non nul.

12 ÷ 3 = 4
(-20) ÷ (-5) = 4
(-18) ÷ 3 = -6

5. Fractions

a/c + b/c = (a+b)/c
1/2 + 1/3 = 3/6 + 2/6 = 5/6
(a/b) × (c/d) = (a×c)/(b×d)
2/3 × 4/5 = 8/15

Pour diviser par une fraction, on multiplie par son inverse.

2/3 ÷ 4/5 = 2/3 × 5/4 = 5/6

6. Priorités opératoires

  1. Parenthèses.
  2. Puissances et racines.
  3. Multiplications et divisions.
  4. Additions et soustractions.

7. Puissances

aⁿ = a × a × ... × a (n facteurs)
  • 2³ = 8
  • 5² = 25
  • (-3)² = 9
  • (-3)³ = -27
aᵐ × aⁿ = aᵐ⁺ⁿ
aᵐ ÷ aⁿ = aᵐ⁻ⁿ (a ≠ 0)
(aᵐ)ⁿ = aᵐˣⁿ
a⁰ = 1 (a ≠ 0)

8. Racines carrées

√a = b signifie b² = a, avec a ≥ 0 et b ≥ 0.
√25 = 5
√49 = 7
√100 = 10

Géométrie

Notions fondamentales

La géométrie étudie les figures, les formes, les longueurs, les angles et l'espace.

  • Le point : indique une position.
  • La droite : ligne illimitée dans les deux sens.
  • Le segment : partie d'une droite limitée par deux points.
  • L'angle : ouverture formée par deux demi-droites.
  • Le triangle : polygone à trois côtés.
Somme des angles d'un triangle = 180°

Fonctions

Chapitre : Généralités sur les fonctions

1. Objectifs du chapitre

À la fin de ce chapitre, l'élève doit être capable de :

  • Définir une fonction numérique.
  • Calculer l'image d'un nombre.
  • Déterminer un antécédent.
  • Construire un tableau de valeurs.
  • Lire une représentation graphique.
  • Reconnaître une fonction linéaire et une fonction affine.

2. Définition d'une fonction

Une fonction numérique est une relation qui associe à chaque nombre x de son ensemble de définition un unique nombre appelé image de x.

f : x → f(x)

Le nombre x est appelé antécédent et le nombre f(x) est son image.

Exemple :
Soit la fonction f définie par :
f(x) = 2x + 3.

Cette fonction associe à chaque nombre x le nombre 2x + 3.

3. Calcul de l'image d'un nombre

Pour calculer l'image d'un nombre, on remplace x par ce nombre dans l'expression de la fonction.

Exemple :
Soit f(x) = 2x + 3.

Calculons l'image de 4.
f(4) = 2 × 4 + 3
f(4) = 8 + 3
f(4) = 11

L'image de 4 est donc 11.
Deuxième exemple :
Soit g(x) = x² - 5.

Calculons g(3).
g(3) = 3² - 5
g(3) = 9 - 5
g(3) = 4

4. Détermination d'un antécédent

Déterminer un antécédent d'un nombre consiste à rechercher la valeur de x dont l'image est ce nombre.

Exemple :
Soit f(x) = 2x + 3.
Cherchons l'antécédent de 13.

On pose :
2x + 3 = 13
2x = 13 - 3
2x = 10
x = 10/2
x = 5

L'antécédent de 13 est 5.
Pour trouver un antécédent, on résout l'équation f(x) = nombre recherché.

5. Tableau de valeurs

Un tableau de valeurs permet de présenter plusieurs nombres et leurs images.

Considérons la fonction :

f(x) = 2x + 1

Calculons les images de -2, -1, 0, 1 et 2.

x -2 -1 0 1 2
f(x) -3 -1 1 3 5
Vérification :
f(-2) = 2 × (-2) + 1 = -3
f(0) = 2 × 0 + 1 = 1
f(2) = 2 × 2 + 1 = 5

6. Représentation graphique d'une fonction

La représentation graphique d'une fonction est l'ensemble des points de coordonnées (x ; f(x)) dans un repère.

Pour tracer une fonction :

  1. Construire un tableau de valeurs.
  2. Tracer un repère avec deux axes perpendiculaires.
  3. Placer les points de coordonnées (x ; f(x)).
  4. Relier les points lorsque la courbe le permet.
Exemple :
Pour f(x) = 2x + 1, on obtient les points :
A(-2 ; -3), B(-1 ; -1), C(0 ; 1), D(1 ; 3) et E(2 ; 5).

Ces points sont alignés. La représentation graphique est une droite.

Illustration de la droite représentant f(x) = 2x + 1.

7. Fonction linéaire

Une fonction linéaire est une fonction définie par une expression de la forme :

f(x) = ax

Le nombre a est appelé coefficient de proportionnalité.

Exemple :
f(x) = 3x.

f(2) = 3 × 2 = 6
f(4) = 3 × 4 = 12
f(-2) = 3 × (-2) = -6

Propriété : La représentation graphique d'une fonction linéaire est une droite qui passe par l'origine du repère.

8. Fonction affine

Une fonction affine est une fonction définie par :

f(x) = ax + b
  • a est le coefficient directeur.
  • b est l'ordonnée à l'origine.
Exemple :
Soit f(x) = 2x + 3.

Le coefficient directeur est a = 2.
L'ordonnée à l'origine est b = 3.

f(1) = 2 × 1 + 3 = 5
f(2) = 2 × 2 + 3 = 7

Propriété : La représentation graphique d'une fonction affine est une droite.

9. Différence entre fonction linéaire et fonction affine

Fonction linéaire Fonction affine
f(x) = ax f(x) = ax + b
b = 0 b peut être non nul
Passe par l'origine Ne passe pas nécessairement par l'origine
Exemple : 3x Exemple : 3x + 2

10. Applications dans la vie courante

Les fonctions permettent de modéliser de nombreuses situations.

Exemple 1 : Achat de cahiers
Un cahier coûte 500 FCFA.
Si x représente le nombre de cahiers achetés, le prix total est :

P(x) = 500x

Pour 4 cahiers :
P(4) = 500 × 4 = 2 000 FCFA.
Exemple 2 : Transport
Un conducteur demande 500 FCFA de prise en charge et 200 FCFA par kilomètre.

Le prix du trajet est :
P(x) = 200x + 500

Pour 5 kilomètres :
P(5) = 200 × 5 + 500
P(5) = 1 500 FCFA.

12. Bilan du chapitre

  • Une fonction associe un nombre à un autre.
  • L'image se calcule en remplaçant x par sa valeur.
  • L'antécédent se trouve en résolvant une équation.
  • Une fonction linéaire est de la forme ax.
  • Une fonction affine est de la forme ax + b.
  • Le graphique d'une fonction affine est une droite.

Statistiques

Définition

Les statistiques permettent de collecter, organiser, représenter et analyser des données.

Moyenne = Somme des valeurs / Effectif total
Exemple : 10, 12 et 14.
Moyenne = (10 + 12 + 14) / 3 = 12.
