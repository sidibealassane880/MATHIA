Algèbre

Chapitre 1 : Les ensembles de nombres

1. Objectifs du chapitre

À la fin de ce chapitre, l'élève doit être capable de :

  • Reconnaître les différents ensembles de nombres.
  • Classer un nombre dans le plus petit ensemble auquel il appartient.
  • Utiliser les symboles d'appartenance et d'inclusion.
  • Comparer des nombres réels.

2. Les nombres naturels

Les nombres naturels sont les nombres utilisés pour compter.

ℕ = {0 ; 1 ; 2 ; 3 ; 4 ; 5 ; ...}

Exemples : 0, 5, 12 et 250 sont des nombres naturels.

3. Les nombres entiers relatifs

Ils comprennent les nombres positifs, les nombres négatifs et zéro.

ℤ = {... ; -3 ; -2 ; -1 ; 0 ; 1 ; 2 ; 3 ; ...}

Exemples : -8, -2, 0, 15.

4. Les nombres décimaux

Un nombre décimal possède une écriture décimale finie.

Exemples : 2,5 ; 0,75 ; -3,125 ; 12.

Exemple : 2,75 est décimal car son écriture comporte un nombre fini de chiffres après la virgule.

5. Les nombres rationnels

Un nombre rationnel est un nombre qui peut s'écrire sous la forme :

a / b avec a ∈ ℤ et b ∈ ℤ, b ≠ 0

Exemples : 1/2 ; -3/4 ; 5 ; 0,25.

6. Les nombres irrationnels

Un nombre irrationnel ne peut pas s'écrire comme le quotient de deux entiers.

Exemples : √2, √3 et π.

7. Les nombres réels

L'ensemble des nombres réels regroupe les nombres rationnels et les nombres irrationnels.

ℕ ⊂ ℤ ⊂ 𝔻 ⊂ ℚ ⊂ ℝ

Les nombres irrationnels appartiennent également à ℝ, mais pas à ℚ.

8. Exemples corrigés

Exemple 1 : Classer 7 dans les ensembles de nombres.
Correction : 7 appartient à ℕ, ℤ, 𝔻, ℚ et ℝ.
Exemple 2 : Classer -4.
Correction : -4 appartient à ℤ, 𝔻, ℚ et ℝ, mais pas à ℕ.
Exemple 3 : Classer √5.
Correction : √5 est irrationnel et appartient à ℝ.

9. À retenir

  • Tout nombre naturel est un entier relatif.
  • Tout entier relatif est un nombre décimal.
  • Tout nombre décimal est rationnel.
  • Tout nombre rationnel est réel.
  • Un nombre irrationnel est réel mais non rationnel.

Chapitre 2 : Opérations sur les nombres réels

1. Objectifs du chapitre

À la fin de ce chapitre, l'élève doit pouvoir :

  • Effectuer des additions et soustractions de nombres réels.
  • Maîtriser les règles de signes.
  • Effectuer des multiplications et divisions.
  • Calculer avec des fractions.
  • Respecter les priorités opératoires.
  • Utiliser les puissances et les racines carrées.

2. Addition des nombres réels

Pour additionner deux nombres réels, on tient compte de leurs signes.

Deux nombres de même signe : on additionne leurs valeurs absolues et on conserve le signe commun.
Exemple 1 :
(+5) + (+3) = +8
(-4) + (-6) = -10
Deux nombres de signes contraires : on soustrait leurs valeurs absolues et on conserve le signe du nombre ayant la plus grande valeur absolue.
Exemple 2 :
(+9) + (-4) = +5
(-12) + (+7) = -5

3. Soustraction des nombres réels

Soustraire un nombre revient à ajouter son opposé.

a - b = a + (-b)
Exemple 1 :
8 - 3 = 8 + (-3) = 5

Exemple 2 :
-5 - 4 = -5 + (-4) = -9

Exemple 3 :
-7 - (-2) = -7 + 2 = -5

4. Multiplication des nombres réels

La multiplication obéit aux règles de signes suivantes :

(+) × (+) = (+)
(-) × (-) = (+)
(+) × (-) = (-)
(-) × (+) = (-)
Exemples :
5 × 3 = 15
(-4) × (-2) = 8
(-6) × 3 = -18
7 × (-2) = -14

5. Division des nombres réels

La division suit les mêmes règles de signes que la multiplication. Le diviseur ne doit jamais être égal à zéro.

(+) ÷ (+) = (+)
(-) ÷ (-) = (+)
(+) ÷ (-) = (-)
(-) ÷ (+) = (-)
Exemples :
12 ÷ 3 = 4
(-20) ÷ (-5) = 4
(-18) ÷ 3 = -6
24 ÷ (-6) = -4

6. Calcul avec les fractions

Une fraction est une écriture de la forme :

a/b avec b ≠ 0
a) Addition de fractions

Lorsque les dénominateurs sont égaux, on additionne les numérateurs.

a/c + b/c = (a+b)/c
2/5 + 1/5 = 3/5

Lorsque les dénominateurs sont différents, on les réduit au même dénominateur.

1/2 + 1/3
= 3/6 + 2/6
= 5/6
b) Soustraction de fractions
a/c - b/c = (a-b)/c
5/7 - 2/7 = 3/7
c) Multiplication de fractions
(a/b) × (c/d) = (a×c)/(b×d)
2/3 × 4/5 = 8/15
d) Division de fractions

Diviser par une fraction revient à multiplier par son inverse.

(a/b) ÷ (c/d) = (a/b) × (d/c)
2/3 ÷ 4/5
= 2/3 × 5/4
= 10/12
= 5/6

7. Les priorités opératoires

Dans un calcul contenant plusieurs opérations, il faut respecter l'ordre suivant :

  1. Les calculs entre parenthèses.
  2. Les puissances et les racines carrées.
  3. Les multiplications et les divisions, de gauche à droite.
  4. Les additions et les soustractions, de gauche à droite.
Exemple 1 :
A = 5 + 3 × 4
A = 5 + 12
A = 17
Exemple 2 :
B = (5 + 3) × 4
B = 8 × 4
B = 32
Exemple 3 :
C = 20 - 12 ÷ 3 + 2
C = 20 - 4 + 2
C = 16 + 2
C = 18

8. Les puissances

Une puissance permet d'écrire plus simplement un produit de facteurs identiques.

aⁿ = a × a × ... × a (n facteurs)

Exemples :

  • 2³ = 2 × 2 × 2 = 8
  • 5² = 5 × 5 = 25
  • (-3)² = 9
  • (-3)³ = -27
Quelques propriétés importantes :
aᵐ × aⁿ = aᵐ⁺ⁿ
aᵐ ÷ aⁿ = aᵐ⁻ⁿ (a ≠ 0)
(aᵐ)ⁿ = aᵐˣⁿ
a⁰ = 1 (a ≠ 0)
a⁻ⁿ = 1/aⁿ (a ≠ 0)
Exemple :
2³ × 2² = 2⁵ = 32

9. Les racines carrées

La racine carrée d'un nombre positif a est le nombre positif dont le carré est égal à a.

√a = b signifie que b² = a, avec a ≥ 0 et b ≥ 0.
√25 = 5 car 5² = 25.
√49 = 7 car 7² = 49.
√100 = 10 car 10² = 100.

Propriétés pour a et b positifs :

√(a × b) = √a × √b
√(a/b) = √a / √b (b ≠ 0)
√(9 × 4) = √9 × √4 = 3 × 2 = 6.

Géométrie

Notions fondamentales

La géométrie étudie les figures, les formes, les longueurs, les angles et les propriétés de l'espace.

  • Le point : indique une position.
  • La droite : ligne illimitée dans les deux sens.
  • Le segment : partie d'une droite limitée par deux points.
  • L'angle : ouverture formée par deux demi-droites de même origine.
  • Le triangle : polygone à trois côtés.

Exemple : La somme des angles d'un triangle est égale à 180°.

Fonctions

Définition

Une fonction associe à chaque nombre x de son ensemble de définition un unique nombre appelé image de x.

f : x → f(x)

Exemple : Soit f(x) = 2x + 3.

L'image de 2 est f(2) = 2 × 2 + 3 = 7.

L'image de 5 est f(5) = 2 × 5 + 3 = 13.

Statistiques

Définition

Les statistiques permettent de collecter, organiser, représenter et analyser des données.

Moyenne : somme des valeurs divisée par l'effectif total.

Moyenne = Somme des valeurs / Effectif total
Exemple : 10, 12 et 14.
Moyenne = (10 + 12 + 14) / 3 = 12.
